# Intro
---
## 1. Series  
> 실무 진행의 Task , R&D 사이드 프로젝트 진행의 트러블 슈팅 등을 서술합니다. 

### 1-1. Orphan Data Cleansing
> 아래 두가지 문제 사항의 해결 경험을 서술합니다.
1. Mongo DB Collection 간의 Data 부모 자식 연관 관계 중 부모 객체가 제거 되었음 에도 제거 되지 않은 고아 데이터 (orphan data) 제거
2. Mongo DB와 ElasticSearch의 Data 정합성이 깨졌을 때의 해결 방안 및 추후 대책 수립 

## 1. Study
> 개인 공부 이력을 기록합니다.

### 1-1. Tech
#### 1. Test Container
* 통합 테스트 진행시 신뢰성 높은 테스트의 구성을 위해 외부 의존 시스템(PostgreSQL, Kafka 등)을 독립적인 Doceker 컨테이너로 구성하여 테스트하는 Test Container 학습 및 실습 기록

### 1-2. AI
#### 1. Knowledge Base System
* 대규모 지식 데이터를 구조화하여 검색, 추론, 질의 응답이 가능한 Knowledge Base System의 아키텍처와 구성 요소에 대한 학습 정리

#### 2. Multi Agent System
* 복잡한 문제 해결을 위해 여러 자율 에이전트가 협력 혹은 경쟁하는 Multi Agent System(MAS)의 구조, 동작 방식, 모델의 학습 기록

### 1-3. DATA
#### 1. ETL Pipeline
* 다양한 데이터 소스로부터 데이터를 추출(Extract), 변환(Transform), 적재(Load)하는 전통적 데이터 처리 방식에 대해 개념, 구조, 역할을 학습 및 정리함

#### 2. Air Flow
* DAG 기반의 워크플로우로 복잡한 데이터 파이프라인을 자동화·스케줄링·모니터링할 수 있는 Apache Airflow의 구조, 개념 및 활용 사례를 학습하고 정리함

### 1-4. CS
* 언어, CS, Algorithm, DB 등 컴퓨터 과학 기초 개념에 대하여 공부한 내용을 정리함

### 1-5. Design Pattern
#### 1. OOP SOLID
* 객체 지향의 기초 개념이 되는 SOLID 디자인 패턴에 대하여 공부하고 실습한 내용을 정리함
