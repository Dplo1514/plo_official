# ETL Pipeline

## 0. 개요
> ETL Pipeline Overview
1. ETL은 Extract, Transform, Load의 약자
   1. Extract : 데이터를 다양한 소스에서 추출
   2. Transform : 비즈니스 요구 사항에 맞게 변환 
   3. Load : 분석 및 저장을 위해 데이터 웨어하우스나 데이터베이스로 적재
2. 이 과정은 대량의 데이터를 효율적으로 처리하고 데이터 기반 의사결정을 지원하는 데 필요한 과정이며   
   ETL Pipeline은 이러한 프로세스를 자동화하여 지속적으로 데이터를 처리할 수 있도록 함.
3. 데이터 통합(Data Integration) 및 품질 관리(Data Quality Management)를 가능하게 하여 데이터를 중앙화된 플랫폼에서 관리하도록 지원함.
4. ETL Pipeline은 데이터 흐름을 구조화하고 자동화하며, 대규모 데이터를 처리할 때 발생할 수 있는 다양한 문제를 해결함.

## 1. 개념
### 1-1. ETL 요구 사항
> ETL은 데이터를 추출, 변환, 적재하는 과정을 통해 다양한 데이터를 통합하여 활용 가능하게 만듦.
1. 데이터 추출(Extract)
   * 데이터를 여러 소스(데이터베이스, API, 클라우드 스토리지, 파일 시스템 등)에서 추출한다.
   * 비구조적 또는 반구조적 데이터를 포함한 모든 종류의 데이터 소스에서 정보를 가져올 수 있도록 설계하여야 한다.
     * ex: MySQL, MongoDB, REST API, CSV 파일 등
     
2. 데이터 변환(Transform)
   * 데이터를 표준화하고, 클렌징하며, 비즈니스 로직에 맞게 조작한다. 
   * 이 과정에서 데이터 타입 변환, 중복 제거, 이상치 처리 등이 수행되어야 한다.
       - ex: 날짜 포맷 통일, 결측값 대체, 특정 열 계산 등

3. 데이터 적재(Load)
   * 변환된 데이터를 분석 가능하도록 데이터 웨어하우스나 데이터베이스로 저장한다.
       - ex: AWS Redshift, Google BigQuery, Postgres 등

### 1-2. ETL의 중요성
> ETL 프로세스는 데이터 관리의 핵심적인 역할을 하며, 다음과 같은 중요성을 가짐
1. 데이터 통합 : 여러 출처에서 데이터를 수집하고 이를 통합하여 일관된 형식으로 저장
2. 데이터 품질 보장 : 데이터 변환 및 정제를 통해 정확하고 신뢰할 수 있는 데이터를 제공
3. 프로세스 자동화 : 데이터 흐름을 자동화하여 수작업의 필요성을 줄이고 효율성을 극대화
4. 데이터 기반 의사결정 : 고품질 데이터를 기반으로 데이터 분석 및 보고서를 생성하여 비즈니스 전략을 수립

## 2. 특징
### 2-1. ETL Pipeline 주요 특징
1. 자동화 가능성 : 정기적으로 데이터를 자동으로 추출, 변환, 적재하도록 예약 작업을 설정할 수 있음.
2. 확장성 : 데이터 양의 증가에도 시스템이 확장되어 효율적으로 데이터를 처리할 수 있음.
3. 유연성 : 다양한 데이터 소스와 형식(예: JSON, XML, CSV, 데이터베이스)을 처리할 수 있음.
4. 에러 관리 및 로깅 : 데이터 처리 중 발생하는 오류를 감지하고 이를 상세히 기록함으로써 문제를 해결할 수 있음
5. 실시간 처리 : 일부 ETL 시스템은 스트리밍 데이터를 실시간으로 처리하여 즉각적인 데이터 분석을 지원함

### 3-2. 단계별 설명
1. Data Source (데이터 소스):
    - 데이터베이스, API, 클라우드 스토리지, IoT 센서, 로그 파일 등 다양한 출처에서 데이터를 수집함.
    - 예: Oracle, SQL Server, NoSQL 데이터베이스, REST API 등.
2. ETL Server (ETL 서버):
    - 데이터를 추출하여 변환 및 로드 작업을 수행하는 중앙 시스템임.
    - 데이터 정규화, 포맷 통일, 비즈니스 로직 적용 등 다양한 처리를 지원함.
3. Data Warehouse (데이터 웨어하우스):
    - 데이터를 분석 및 저장하기 위한 구조화된 저장소임.
    - 데이터 웨어하우스는 대규모 데이터 분석에 최적화되어 있음.
    - 예: Snowflake, AWS Redshift, Google BigQuery.
4. Business Intelligence Tools (비즈니스 인텔리전스 툴):
    - 데이터를 시각화하고 분석하여 인사이트를 제공하는 도구임.
    - Tableau, Power BI, Looker와 같은 툴을 활용함.
5. Insights & Reports (인사이트 및 보고서):
    - 분석 결과를 기반으로 비즈니스 의사결정을 지원하며, 대시보드와 보고서를 통해 데이터를 제공함.
